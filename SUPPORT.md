# Support

RustySerial is a small serial console TUI plus a Bevy launcher GUI. It ships as open source **without a support promise**.

This is a small operation. Public issues are read and appreciated, but response
is best-effort and can be slow. Treat RustySerial as software you are willing to
operate and debug yourself.

## Maturity

See the README for what is implemented and how far it has been exercised.
Where the README is unclear, assume a capability is less proven than you would
like and verify it yourself.

Nothing here is feature-gated, license-keyed, or held back for a paid tier.
Where something is missing, it is unfinished — not withheld.

## Getting help

- **Bugs and regressions** — open an issue with the detail below.
- **Questions and design discussion** — open an issue; expect a slower reply.
- **Security issues** — do not open a public issue. See [SECURITY.md](SECURITY.md).

## Reporting issues

Include:

- host OS and version
- the serial device and adapter chipset
- baud rate and port settings in use
- whether it fails in the TUI, the GUI launcher, or both
- commit
- what you expected, what happened, and the exact steps to reproduce
- logs or backtraces, as text rather than screenshots where possible
